  <action>
    1. Create `scripts/pipeline/query-lessons.ts`:
       - Export `queryLessonsForScope(opts: GenerateOptions): Promise<LessonTarget[]>`
       - Uses `supabase` from `scripts/lib/supabase.ts`
       - Scope resolution (only one scope flag is used at a time, validated in generate.ts):

         **--pillar N** (N is display_order number):
         - Query `pillars` where `display_order = N` and `deleted_at IS NULL` to get pillar row
         - Query `semesters` where `pillar_id = pillar.id` and `deleted_at IS NULL`
         - Query `courses` where `semester_id IN (semester_ids)` and `deleted_at IS NULL`
         - Query `lessons` where `course_id IN (course_ids)` and `deleted_at IS NULL`, ordered by course display_order then lesson display_order

         **--semester slug**:
         - Query `semesters` where `slug = slug` and `deleted_at IS NULL`
         - Resolve pillar via semester.pillar_id
         - Query courses and lessons as above

         **--course slug**:
         - Query `courses` where `slug = slug` and `deleted_at IS NULL`
         - Resolve semester and pillar via course.semester_id
         - Query lessons in that course

         **--lesson slug**:
         - Query `lessons` where `slug = slug` and `deleted_at IS NULL`
         - Resolve course, semester, pillar via lesson.course_id

       - For each lesson row, construct a `LessonTarget` by joining pillar/semester/course metadata
       - Parse semester number from the semester's display_order or name (semester 1 = beginner, etc.)
       - If no lessons found for the scope, throw an error with helpful message

    2. Create `scripts/pipeline/seed-lesson.ts`:
       - Export `seedLesson(params: { lessonId: string, mdxContent: string, quizQuestions: GeneratedQuizQuestion[], dryRun: boolean }): Promise<void>`
       - Uses `supabase` from `scripts/lib/supabase.ts`

       - **Dry-run mode** (`dryRun === true`):
         - Print `\n--- DRY RUN: MDX OUTPUT ---\n` followed by the MDX content to stdout
         - Print `\n--- DRY RUN: QUIZ QUESTIONS ---\n` followed by JSON.stringify(quizQuestions, null, 2)
         - Return without any DB writes

       - **Normal mode:**
         a. Insert quiz questions into `quiz_questions` table:
            - For each `GeneratedQuizQuestion`, insert a row with:
              - `lesson_id: params.lessonId`
              - `question_type: q.questionType`
              - `question_text: q.questionText`
              - `context: q.context`
              - `options: q.options` (JSONB — the array of `{ id, text, isCorrect }`)
              - `explanation: q.explanation`
              - `display_order: index + 1`
            - Use `.insert()` with `.select('id')` to get back the generated UUIDs
            - If quiz questions already exist for this lesson AND we're in --force mode, delete existing questions first (`DELETE FROM quiz_questions WHERE lesson_id = ?`) before inserting new ones

         b. Replace PLACEHOLDER_N references in MDX with real UUIDs:
            - For each inserted question, replace `PLACEHOLDER_${index + 1}` in the MDX string with the real UUID returned from the insert
            - If any PLACEHOLDER_N remains unreplaced, log a warning

         c. Update the lesson row:
            - `.update({ mdx_content: finalMdx, updated_at: new Date().toISOString() }).eq('id', params.lessonId)`
            - The DB trigger `trg_lessons_version` automatically captures the prior content into `lesson_versions`
            - Check the response — if 0 rows affected, throw error (lesson row doesn't exist, per Pitfall 4 in RESEARCH.md)

    IMPORTANT considerations:
    - Use `.update()` not `.insert()` for lesson seeding — lesson rows already exist from curriculum seed (see Pitfall 4 and Anti-Patterns in RESEARCH.md)
    - Quiz questions use `.insert()` since they are new rows
    - The `correct_answer` field on quiz_questions is derived from the option marked `isCorrect: true` — extract the text of the correct option
    - Supabase `.insert()` returns `{ data, error }` — always check error
  </action>

       e. **Sequential lesson loop** (GEN-04 progress + per CONTEXT.md: one at a time, no parallel):
          ```
          for (let i = 0; i < lessons.length; i++) {
            const lesson = lessons[i]
            const startTime = Date.now()
            printLessonHeader(i + 1, lessons.length, lesson.name)

            try {
              // Stage 1: Research
              printStage('Researching', 'start')
              const researchNotes = await researchTopic({ ... })
              printStage('Researching', 'done', Date.now() - stageStart)

              // Stage 2: Generate
              printStage('Generating', 'start')
              let { mdx, quizQuestions } = await generateLesson({ ... })
              printStage('Generating', 'done', Date.now() - stageStart)

              // Stage 3: Review
              printStage('Reviewing', 'start')
              const reviewed = await reviewLesson({ ... })
              mdx = reviewed.mdx
              quizQuestions = reviewed.quizQuestions
              printStage('Reviewing', 'done', Date.now() - stageStart)

              // Stage 4: Validate
              printStage('Validating', 'start')
              const validation = await validateMdx(mdx)
              if (!validation.valid) {
                // Auto-retry once on validation failure (per Claude's discretion in CONTEXT.md)
                console.warn('  Validation failed, retrying generation...')
                const retry = await generateLesson({ ... })
                mdx = retry.mdx
                quizQuestions = retry.quizQuestions
                const retryValidation = await validateMdx(mdx)
                if (!retryValidation.valid) {
                  throw new Error(`Validation failed after retry: ${retryValidation.errors.join(', ')}`)
                }
              }
              printStage('Validating', 'done', Date.now() - stageStart)

              // Stage 5: Seed
              printStage('Seeding', 'start')
              await seedLesson({ lessonId: lesson.id, mdxContent: mdx, quizQuestions, dryRun: opts.dryRun })
              printStage('Seeding', 'done', Date.now() - stageStart)

              // Track for lesson continuity
              priorLessonSummaries.push(`Lesson: "${lesson.name}" - Key topics covered in this lesson`)

              results.push({ lessonId: lesson.id, lessonName: lesson.name, status: opts.dryRun ? 'dry-run' : 'generated', durationMs: Date.now() - startTime })
            } catch (err) {
              printStage('', 'fail')
              const errorMsg = err instanceof Error ? err.message : String(err)
              console.error(`  Error: ${errorMsg}`)
              results.push({ lessonId: lesson.id, lessonName: lesson.name, status: 'failed', durationMs: Date.now() - startTime, error: errorMsg })
              // Continue to next lesson — don't crash the entire batch
            }
          }
          ```
