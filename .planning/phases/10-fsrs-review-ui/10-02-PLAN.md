**FSRS singleton:** `const f = fsrs()` at module level (same default params as server action).

**Interval hint computation function** (`computeIntervalHints`):
- Takes a `DueCardForReview` and returns `Record<1|2|3|4, string>` (rating -> human-readable interval)
- Reconstructs the ts-fsrs Card object from the DueCardForReview fields:
  ```typescript
  const fsrsCard = {
    due: new Date(card.due),
    stability: card.stability,
    difficulty: card.difficulty,
    elapsed_days: card.elapsed_days,
    scheduled_days: card.scheduled_days,
    learning_steps: card.learning_steps,
    reps: card.reps,
    lapses: card.lapses,
    state: card.state,
    last_review: card.last_review ? new Date(card.last_review) : undefined,
  }
  ```
- Calls `f.repeat(fsrsCard, now)` to get all 4 outcomes simultaneously
- **Format interval** (critical for FSRS-05 -- Pitfall 6 from research):
  - If `scheduled_days === 0`: compute minutes from `(due.getTime() - now.getTime()) / 60000`, minimum 1 minute. Format as "1 min" / "N min"
  - If `scheduled_days > 0`: format as "1 day" / "N days"
- Returns object keyed by rating number (1=Again, 2=Hard, 3=Good, 4=Easy)

**ReviewSession component** (`export function ReviewSession({ cards }: { cards: DueCardForReview[] })`):
- **State:** `currentIndex` (number, starts at 0), `isAnswerRevealed` (boolean, starts false), `isPending` from `useTransition`
- **Router:** `useRouter()` for `router.refresh()` after last card
- **Current card:** `cards[currentIndex]` -- guard with `if (!currentCard) return null`
- **Interval hints:** Call `computeIntervalHints(currentCard)` during render (synchronous, pure math)
- **isLastCard:** `currentIndex === cards.length - 1`

**handleReveal function:** Sets `isAnswerRevealed` to `true`.

**handleRate function** (rating: 1|2|3|4):
- Wraps in `startTransition(async () => { ... })` to get `isPending` for free
- `await submitFsrsReview({ cardId: currentCard.cardId, rating })` -- FSRS-06 persistence
- If last card: call `router.refresh()` -- triggers RSC re-render showing "All caught up"
- If not last card: increment `currentIndex`, set `isAnswerRevealed` to `false`

```typescript
function formatTimeUntil(dueIso: string): string {
  const diff = new Date(dueIso).getTime() - Date.now()
  if (diff <= 0) return 'very soon'

  const mins = Math.round(diff / 60000)
  if (mins < 60) return `${mins} ${mins === 1 ? 'minute' : 'minutes'}`

  const hours = Math.round(diff / 3600000)
  if (hours < 24) return `${hours} ${hours === 1 ? 'hour' : 'hours'}`

  const days = Math.round(diff / 86400000)
  return `${days} ${days === 1 ? 'day' : 'days'}`
}
```
