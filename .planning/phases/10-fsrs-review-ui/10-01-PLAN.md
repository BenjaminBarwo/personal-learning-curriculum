2. **Create `getDueCardsForReview()` server action:**
- Call `auth()` for userId, return `[]` if not authenticated
- Use `createAdminSupabaseClient()` (matches project pattern -- admin client in all server actions)
- Query `fsrs_cards` with PostgREST foreign key expansion: `.select('id, question_id, due, stability, difficulty, elapsed_days, scheduled_days, learning_steps, reps, lapses, state, last_review, quiz_questions(question_text, question_type, correct_answer, accepted_answers, explanation, options)')` -- the joined relation name is `quiz_questions` (table name, not FK column name)
- Filter: `.eq('user_id', userId).lte('due', new Date().toISOString())`
- Order: `.order('due', { ascending: true })` -- oldest-due first
- Map results to `DueCardForReview[]`:
  - Filter out rows where `row.quiz_questions` is null (orphaned cards from soft-deleted questions -- Pitfall 3 from research)
  - Cast `row.quiz_questions?.options as unknown as QuizOption[] | null` (same cast pattern as Quiz component)
- Return empty array on error (log with console.error)

3. **Create `getNextDueCard()` server action:**
- Call `auth()` for userId, return `null` if not authenticated
- Use `createAdminSupabaseClient()`
- Query: `.from('fsrs_cards').select('due').eq('user_id', userId).gt('due', new Date().toISOString()).order('due', { ascending: true }).limit(1).maybeSingle()`
- Return `{ due: data.due }` or `null` on error/no data
- Type the return as `Promise<{ due: string } | null>`
