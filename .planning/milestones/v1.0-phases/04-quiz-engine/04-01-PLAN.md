**Quiz.tsx** — Create a 'use client' interactive quiz component handling all 5 question types:

1. Accept `{ questionId: string }` props (this is what MDX authors write: `<Quiz questionId="uuid" />`)
2. Call `useQuizContext()` to get question data and answer state
3. Call `createClerkSupabaseClient()` at component top level (**NOT inside handlers** — it uses useSession hook internally)
4. Call `useSession()` to get `session?.user?.id` for the user_id field, with fallback to `HARDCODED_USER_ID` from `@/constants/user`
5. Track `localSelected` (string | null) and `isSubmitting` (boolean) with useState
6. Track `timeStarted` with useRef<number | null> — set to `Date.now()` on first render via useEffect (for time_spent_seconds)
7. Look up question from context: `questions[questionId]`. If not found, render graceful fallback (a subtle "Question not available" message styled with `text-text-muted` — never crash)
8. Look up existing answer from context: `answers[questionId]`. If `submitted`, show locked result (cannot re-answer within session)

**Correctness evaluation function** `computeIsCorrect(question, selectedAnswer)`:
- For `recall` type: check `accepted_answers` array with case-insensitive `.toLowerCase().trim()` comparison
- For all other types (`multiple_choice`, `application`, `analysis`, `comparison`): compare `selectedAnswer === question.correct_answer`

**handleSubmit async function:**
- Guard: return early if `!localSelected || submitted || isSubmitting`
- Compute `isCorrect` using `computeIsCorrect`
- Set `isSubmitting = true`
- Compute `timeSpent` from `timeStarted.current` (seconds, rounded)
- Try: COUNT existing attempts for this question+user, then INSERT into quiz_attempts:
  ```
  { user_id, question_id: questionId, lesson_id: question.lesson_id,
    selected_answer: localSelected, correct_answer: question.correct_answer ?? '',
    is_correct: isCorrect, time_spent_seconds: timeSpent,
    attempt_number: (count ?? 0) + 1 }
  ```
- On error: `console.error('[Quiz] Failed to persist attempt:', error)` — do NOT block UX
- Always (try/catch/finally): call `submitAnswer(questionId, localSelected, isCorrect)` to update context, set `isSubmitting = false`

**Rendering — question type UI variants:**

All types share the same outer container and feedback section. They differ in the input mechanism:

a) **multiple_choice / application / analysis / comparison**: Radio-button-style option list
   - Cast `question.options as QuizOption[]` (runtime JSONB → typed array)
   - Label each option with A, B, C, D, E
   - For `application` and `analysis`: render `question.context` in a styled block above the options (bg-surface-card border border-border-subtle rounded-lg p-4 text-sm text-text-secondary italic mb-4)
   - Selected state: highlighted border + bg
   - After submit: correct option gets green (emerald-500) border/bg, wrong selected gets red (red-500), unselected dim to opacity-50
   - Disable all options after submission

b) **recall**: Text input field
   - `<input type="text">` with `autoCapitalize="off" autoCorrect="off" spellCheck={false}` (per research recommendation)
   - Placeholder: "Type your answer..."
   - On Enter key: trigger submit
   - After submit: show the accepted answers list below for learning

**Feedback section** (shown after `submitted === true`, regardless of correct/incorrect):
- Correct: emerald background tint, "Correct!" heading
- Incorrect: red background tint, "Not quite" heading
- Always show `question.explanation` below the heading
- Use dark-mode-compatible colors: emerald-500/10 bg, emerald-500/30 border for correct; red-500/10 bg, red-500/30 border for incorrect

**Submit button:**
- Text: "Check Answer" (idle), spinner + "Checking..." (submitting)
- Disabled when: no answer selected, already submitted, or isSubmitting
- Style: bg matching pillar color pattern OR a neutral accent. Use `bg-blue-600 hover:bg-blue-700 text-white` for the submit button (consistent neutral accent that works in both themes)
- After submission: button disappears (feedback section replaces it)

**Outer container styling:**
